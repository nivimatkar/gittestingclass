Here is the one-line summary of each command's purpose:

ssh-keygen: Generates a new SSH key pair for secure, passwordless authentication.

uname -a: Displays detailed system information, including OS name, hostname, and kernel version.

top: Displays real-time system processes and resource usage (CPU, memory).

htop: Provides an interactive, color-coded view of running processes and system resources.

uptime: Shows how long the system has been running, active users, and system load averages.

last: Displays a list of recently logged-in users and session details.

df: Shows disk space usage for all mounted filesystems in default blocks.

df -h: Displays disk space usage in human-readable format (e.g., GB, MB).

pwd: Prints the absolute path of the current working directory.

du: Displays estimated file and directory space usage.

ping [www.google.com](https://www.google.com): Tests network connectivity and response time to Google's server.

who: Displays users who are currently logged into the system.

w: Shows logged-in users and what processes they are currently running.

whoami: Prints the username of the currently active user.

ls: Lists the files and directories inside the current directory.

cd /var/log: Navigates into the /var/log system logs directory.

ls: Lists files in the current /var/log directory.

locate *.log: Searches the system database for files ending in .log (note: shell expands *.log first).

apt-get update: Updates local package index files with the latest available repository versions.

apt install plocate: Installs the plocate package for fast file searching using a cached database.

locate *.log: Searches the plocate database for log files matching local directory patterns.

ls: Lists files and directories in the working directory.

locate *.log: Re-executes the log search via the locate database.

find *.log: Searches the current directory for files matching .log extensions.

locate '*.log': Searches the system database for all files ending in .log, passing the literal wildcard.

mkdir myfiles ; touch myfiles/{a.txt,b.txt,c.txt}: Creates directory myfiles and three empty files inside it (a.txt, b.txt, c.txt).

ls: Lists current directory content to verify myfiles folder creation.

ls myfiles: Displays contents inside the myfiles directory.

tar -cvf allfiles.tar myfiles: Creates an uncompressed archive named allfiles.tar containing the myfiles directory.

ls: Lists directory contents to verify creation of allfiles.tar.

tar -xvf allfiles.tar: Extracts the contents of allfiles.tar into the current working directory.

adduser kishore: Interactively creates a new user account named kishore.

su kishore: Switches the user session to user kishore.

passwd kishore: Changes or sets the password for user kishore.

usrdel kishore: Failed command attempt (misspelled userdel).

userdel kishore: Deletes the system user account kishore.

su kishore: Attempts to switch to user kishore (fails if user was successfully deleted).

addgroup devops45: Creates a new user group named devops45.

getent group: Lists all user groups defined in system databases.

adduser om: Interactively creates a new system user named om.

getent group: Displays system groups to review current group configurations.

usermod -a -G devops45 om: Appends user om to the existing group devops45.

getent group: Lists groups to verify om was added to devops45.

chage: Displays usage instructions for changing user password expiration policies.

cd /etc/passwd: Fails to change directory because /etc/passwd is a file, not a directory.

cd /etc/: Navigates into the system configuration directory /etc.

ls: Lists files and configuration directories inside /etc.

cat passwd: Displays account and user profile details stored in /etc/passwd.

cat shadow: Attempts to view encrypted password details in /etc/shadow (requires root privileges).

cat group: Displays system group memberships and group IDs stored in /etc/group.

vi sudoers: Opens the administrative privilege policy file in the vi text edito

history: Outputs a numbered list of previously executed shell commands.
